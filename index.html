ML & Cloud-Based Turbulence Prediction

Published — IEEE ICADS 2026

Satellite-driven ML pipeline deployed on AWS for real-time turbulence severity classification using INSAT-3D data.

Random Forest XGBoost AWS EC2 Docker Flask

The Problem

Traditional turbulence detection methods are reactive and radar-dependent, making Clear-Air Turbulence (CAT) difficult to anticipate. Processing large-scale satellite HDF5 datasets (60M+ rows) for ML modeling required a robust data engineering and deployment strategy.

What I Built

  • Processed INSAT-3D Level-2B satellite datasets to engineer proxy labels for turbulence severity classification
  • Trained Random Forest and XGBoost classifiers for multi-class severity prediction (Low/Moderate/Severe)
  • Deployed inference pipeline on AWS EC2 with Docker containerization
  • Designed browser-based interface for operational usage via Flask + Gunicorn

What's Next

Phase II (ongoing): Extending to Deep Learning models for improved spatiotemporal turbulence forecasting.

Co-author: Dr. Brijmohan Lal Sahu · Scopus Indexed

Serverless Malware Scanner

Completed

Fully serverless malware detection system on AWS — event-driven scanning with zero infrastructure maintenance.

AWS Lambda Amazon S3 Java CloudWatch SNS

Architecture

  • S3 upload events trigger Lambda function (Java 17) for real-time file analysis
  • Malware inspection pipeline with configurable scanning logic (extensible to ClamAV)
  • CloudWatch logging + SNS alerting for security teams on threat detection
  • Deployed entirely within AWS Free Tier — zero cost, zero maintenance

Key Design Decision

Event-driven serverless architecture eliminates idle compute costs and scales automatically with upload volume. IAM permissions scoped to least-privilege S3 read + Lambda execution.
